# nodebb-plugin-bina-gallery

גלריית יצירות AI לפורום [בינה טופ](https://bina.top), על בסיס NodeBB 4.

הגלריה בנויה על קטגוריה רגילה בפורום: כל נושא בקטגוריה הוא יצירה אחת, והתמונה הראשונה בו היא מה שמוצג בגלריה. תגובות, התראות, חיפוש, דיווחים וניהול ממשיכים לעבוד כרגיל. כל התמונות מאוחסנות בפורום עצמו, בלי תלות באתרים חיצוניים.

## מה יש

- **דף `/gallery`:** רשת תמונות (masonry) שבה כל תמונה נשארת בפרופורציות המקוריות שלה. במחשב יש 4 עמודות ובטלפון 2.
- **"יצירת היום":** היצירה שקיבלה הכי הרבה לייקים ב־24 השעות האחרונות.
- **מיון:** חדשות / הכי אהובות היום / השבוע / החודש / כל הזמנים.
- **צפייה בגדול (lightbox):** חיצים ומקלדת, לייק, וקישור לנושא המלא.
- **כפתור "שתפו יצירה":** פותח נושא חדש בקטגוריה עם תבנית (כלי / מודל, פרומפט).
- **אישור יצירות (אופציונלי):** יצירות חדשות נכנסות לתור האישור של NodeBB. לא נכנסים לתור: מנהלים, מפקחים, וחברי קבוצת "יוצרים מאושרים". תגובות לא עוברות אישור.
- **ניקוד יוצרים נפרד:**
  - לייקים על יצירות (הפוסט הראשון בנושא) לא נכנסים למוניטין הרגיל של הפורום, אלא לניקוד יוצר נפרד.
  - הניקוד מוצג בטבלת "יוצרים מובילים" (`/gallery?sort=creators`) ובפרופיל המשתמש.
  - לייקים על תגובות ממשיכים להיספר במוניטין כרגיל.
- **תמונות מוקטנות:** הרשת מציגה עותקי WebP קטנים (600px, ו־1400px ל"יצירת היום"). הם נוצרים בצפייה הראשונה ונמחקים כשהיצירה נמחקת או מועברת מהגלריה.
- **עמוד יצירה (`/gallery/:tid`):** לכל יצירה יש עמוד משלו, עם כתובת לשיתוף ו־og:image של היצירה. בעמוד:
  - התמונה בגדול, וחצים (גם במקלדת) ליצירה הבאה והקודמת.
  - היוצר, עם כפתור מעקב.
  - לבבות, העתקת קישור, גודל מלא, ועריכה ליוצר.
  - אישור השימוש, הכלי, הסגנונות והפרומפט, עם כפתור העתקה.
  - תגובות, שמתעדכנות בזמן אמת, וטופס תגובה.
  - "עוד מהיוצר".
  כרטיסים בגלריה מקשרים לעמוד הזה. לחיצה רגילה עדיין פותחת את התצוגה המוגדלת.
- **לשונית "יצירות בגלריה" בפרופיל (`/user/:slug/gallery`):** היצירות של המשתמש, מספר היצירות והלבבות, ואותה רשת ותצוגה מוגדלת.
- **חלון שיתוף יצירה:** כפתור "שתפו יצירה" פותח חלון של הגלריה. בחלון בוחרים תמונה (גרירה, הדבקה או בחירה), כותרת לא חובה, כלי או מודל, עד 3 סגנונות והפרומפט.
  - התמונה עולה בהעלאה הרגילה של הפורום, והיצירה נוצרת דרך ה־API הרגיל, ולכן הרשאות, תור אישור והגבלות קצב פועלים כרגיל.
  - בלי כותרת, היצירה נקראת "יצירה של <שם>".
- **אישור שימוש:** בחלון השיתוף היוצר בוחר אם הוא מאשר לאחרים להשתמש בתמונה: לא מאשר (רק באישור ממנו), שימוש אישי, או שימוש אישי ומסחרי. הבחירה נכתבת בפוסט (`**אישור שימוש:**`), נשמרת בשדה `bgUsage`, ומוצגת בתצוגה המוגדלת. בפעם הבאה החלון מציע את הבחירה האחרונה (`binaGalleryUsage` של המשתמש).
- **פרטי יצירה מובנים:** הכלי, הסגנונות והפרומפט נכתבים בפוסט עם תוויות קבועות (`**הכלי / המודל:**`, `**סגנונות:**`, `**הפרומפט:**`). השרת מעתיק אותם לשדות הנושא `bgTool`, `bgStyles` ו־`bgPrompt` בפרסום (גם אחרי אישור מהתור), בעריכה ובהעברה לגלריה.
  - בתצוגה המוגדלת מוצגים הכלי והסגנונות, וכפתור "פרומפט" פותח את הפרומפט עם כפתור העתקה. הפרומפט נטען לפי הצורך מ־`GET /api/v3/plugins/bina-gallery/items/:tid`.
- **סידור לפי שורות:** הרשת בנויה כעמודות, אבל כל יצירה נכנסת לפי הסדר לעמודה הנמוכה ביותר כרגע. כך היצירות החדשות ביותר תמיד בשורה העליונה, מימין לשמאל. השרת מוסיף לכל תמונה רוחב וגובה, כדי שהמקום שלה יישמר עוד לפני שהיא נטענת. "טען עוד" רק מוסיף כרטיסים, בלי להזיז את הקיימים.
- **נפרד מרשימות הפורום:** יצירות ותגובות עליהן לא מופיעות ב"אחרונים", ב"לא נקראו" (כולל המונה בתפריט ופס "נושאים חדשים"), ב"פופולרי", ב"מובילים", ב־RSS, בתקציר המייל ובכרטיסים של דף הבית. הן כן מופיעות בגלריה, בקטגוריית הגלריה עצמה (גם כשבוחרים אותה ב"אחרונים" או ב"לא נקראו"), בדפי תגיות ובחיפוש.
  - כדי שהיצירות לא יוצגו גם באריח של קטגוריית האב, מגדירים לקטגוריית הגלריה "מספר תגובות אחרונות" 0.

## התקנה

```bash
cd /path/to/nodebb
npm install git+https://github.com/szs-770/nodebb-plugin-bina-gallery.git
./nodebb activate nodebb-plugin-bina-gallery
./nodebb build && ./nodebb restart
```

אחר כך, בניהול ← תוספים ← **גלריית יצירות**:
1. בוחרים את קטגוריית הגלריה.
2. מפעילים או מכבים את אישור היצירות.
3. מגדירים את שם קבוצת היוצרים המאושרים. את הקבוצה עצמה צריך ליצור בניהול ← קבוצות.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `library.js` | צד שרת: הנתיב `/gallery`, הגדרות, hook לתור האישור, ניקוד היוצרים (hooks של הצבעות ושל נושאים), תמונות מוקטנות, והוצאת היצירות מרשימות הפורום |
| `templates/gallery.tpl` | תבנית הדף |
| `public/gallery-item.js` | עמוד יצירה (`forum/gallery-item`) |
| `public/account-gallery.js` | לשונית הפרופיל (`forum/account/gallery`) |
| `templates/gallery-item.tpl`, `templates/account/gallery.tpl`, `templates/partials/bina-gallery/card.tpl` | תבניות של עמוד היצירה, לשונית הפרופיל וכרטיס יצירה משותף |
| `public/gallery.js` | צד לקוח (`forum/gallery`): lightbox, לייקים, טעינת עוד, כפתור השיתוף |
| `public/gallery.scss` | עיצוב, כולל מצב כהה ומובייל |
| `public/profile.js` | הוספת ניקוד היוצר לסטטיסטיקות בפרופיל |
| `public/forum-lists.js` | מונע מיצירות חדשות להקפיץ את פס "נושאים חדשים" ברשימות הפורום |
| `templates/admin/plugins/bina-gallery.tpl`, `public/admin.js` | דף ההגדרות בניהול |

### נתונים
- `settings:bina-gallery`: השדות `cid`, `moderation`, `approvedGroup`.
- `bina-gallery:scores` (sorted set): ניקוד היוצר לכל uid, כלומר upvotes פחות downvotes על יצירות שלא נמחקו.
- `bina-gallery:creations` (sorted set): מספר היצירות לכל uid.
- `bina-gallery:thumbs:<tid>` (set): שמות קובצי התמונות המוקטנות של כל יצירה, כדי למחוק אותם גם אחרי מחיקה לצמיתות.

## רעיונות להמשך
- אתגרים ותחרויות שבועיים (תגית לאתגר, לשונית בגלריה, בחירת זוכים).
- פילטר לפי כלי או מודל.
- עמוד יצירה מלא, חלון העלאה ייעודי, ולשונית "גלריה" בפרופיל.
